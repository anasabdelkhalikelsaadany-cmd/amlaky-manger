# مدير أملاكي (Molaky Manager)

تطبيق أندرويد (Kotlin + Jetpack Compose + Room) لإدارة الأملاك المؤجرة: وحدات، مستأجرين، إيجارات، متأخرات، تنبيهات، ونسخ احتياطي.

## المميزات
- وحدات (شقة/محل/مكتب...) بالعنوان والموقع على الخريطة وبيانات المستأجر والعقد.
- تسجيل دفعات لأي شهر (مع تاريخ الدفع) وحذفها بتأكيد، وحساب المتأخرات بدقة شهراً بشهر.
- زيادة سنوية (نسبة أو مبلغ) تُطبَّق بزر واحد ويُحسب الإيجار القديم والجديد صح في المتأخرات.
- داشبورد: إجمالي المتأخرات، المتوقع والمحصّل والمتبقي هذا الشهر، وعقود/زيادات قريبة.
- بحث وفلترة (متأخر / مستحق لاحقاً / مسدد / متوقف).
- اتصال بالمستأجر وتذكير عبر واتساب برسالة جاهزة.
- تنبيه يومي الساعة 9 ص (متأخرات كل 3 أيام + عقود وزيادات قريبة).
- نسخ احتياطي واسترجاع JSON — الاسترجاع يتحقق من الملف أولاً ويتم داخل Transaction (لا يمسح بياناتك لو الملف سيئ).
- واجهة عربية RTL، فاتح/داكن.

## طرق الحصول على APK
### 1) Android Studio
1. افتح مجلد `MolakyManager` (Android Studio Ladybug أو أحدث) وانتظر Gradle Sync.
2. `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
3. الملف في: `app/build/outputs/apk/debug/app-debug.apk` — انقله للموبايل وثبّته (اسمح بالتثبيت من مصدر غير معروف).

### 2) بدون Android Studio (GitHub Actions)
1. ارفع المجلد كله على مستودع GitHub جديد (يشمل `.github/workflows`).
2. من تبويب **Actions** شغّل **Build APK** (Run workflow).
3. بعد دقائق نزّل `MolakyManager-debug-apk` من Artifacts وفك الضغط وثبّت `app-debug.apk`.

## ملاحظات
- ملف APK الـ debug يصلح للاستخدام الشخصي. للنشر على Google Play ستحتاج توقيع Release.
- البيانات محلية على الجهاز فقط (`allowBackup=false`) — خد نسخة احتياطية من شاشة الإعدادات بشكل دوري.
- التنبيهات تحتاج إذن الإشعارات، وبعض الأجهزة (Xiaomi/Oppo...) تحتاج استثناء التطبيق من توفير البطارية.
- الإيجار يُحسب لكل شهر من "بداية تتبع الإيجار" التي تختارها لكل وحدة، فالشهور السابقة لا تظهر كمتأخرات.
- الاختبارات في `app/src/test` (شغّلها بـ `gradle testDebugUnitTest`).
